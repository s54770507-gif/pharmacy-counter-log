# 櫃台推薦紀錄

藥局櫃台用的匿名客人紀錄工具，記錄性別、年齡區間、推薦結果、拒絕原因和來店目的。

- 前端：本 repo 的 `index.html`，以 GitHub Pages 發布。
- 後端：Google 試算表，以 Apps Script（`apps-script/Code.gs`）讀寫。
- 不記姓名、電話等個資。

## 一次性設定

1. 新建一份 Google 試算表，選「擴充功能 → Apps Script」。
2. 把 `apps-script/Code.gs` 的內容整份貼進去，並把 `TOKEN` 換成自己的長亂碼（通行碼）。
   通行碼不要提交到這個 repo。
3. 按「部署 → 新增部署作業 → 類型：網頁應用程式」：
   - 執行身分：**我**
   - 誰可以存取：**任何人**（前端要能直接呼叫；資料由通行碼保護）
4. 首次部署時，Google 會要求授權存取試算表，按允許。
5. 複製部署後拿到的網址（`https://script.google.com/macros/s/…/exec`）。
6. 用手機打開 GitHub Pages 網址，輸入步驟 5 的網址和通行碼。每支手機只需設定一次。

修改 `Code.gs` 後，要到「管理部署作業」編輯原本的部署並選「新版本」，網址才會維持不變。

## 資料

試算表會自動建立「紀錄」工作表，每位客人一列：
`id、時間戳、日期、時間、星期、性別、年齡、推薦結果、拒絕原因、來店目的`。

沒有網路時，紀錄會先暫存在手機上，畫面顯示「N 筆待上傳」，恢復連線後自動補傳。
